# CloverFinancialInsightsPipeline

## Purpose

is to create an ETL pipeline that extracts raw POS data and deposits in a cetralized db. An analytics engine pulls raw data and derives actionable JSON, which is then fed into an LLM that compares and contrasts against current market trends and data to create summaries, reports and recomendations.

### SETUP

copy env example into your own env file and use that to store tokens and urls.
